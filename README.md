# Bongoportus Workspace

This workspace contains the **Bongoportus E-Commerce Platform**.

## 📁 Project Structure

```
bongoportus/
└── shipementwebsite/    # Main e-commerce application (Vite + React)
```

## 🚀 Quick Start

```bash
cd shipementwebsite
npm install
npm run dev
```

## 📦 What's Inside

The `shipementwebsite` folder contains a full-featured multi-vendor e-commerce platform with:
- 🛒 Customer shopping experience
- 🏪 Seller/vendor management panel
- 🎛️ Admin dashboard
- 💳 Payment processing (Stripe)
- 💬 Real-time messaging
- 📦 Order management
- ⭐ Reviews & ratings
- And much more!

## 🗂️ Database

- **Setup**: Run `database-setup.sql` in your Supabase SQL editor
- **Seed Data**: Run `2_seed.sql` to add sample products and data

## 🛠️ Tech Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Backend**: Supabase (PostgreSQL + Auth + Storage)
- **Payments**: Stripe
- **State**: Zustand + React Context
